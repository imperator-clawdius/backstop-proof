# Backstop Proof App Store Listing

## Title

Backstop Proof

## Subtitle

Packing proof and chargeback evidence packs for Shopify orders.

## Introduction

Seal packing photos, tracking, and order facts into bank-ready evidence packs when disputes hit.

## Feature Bullets

- Capture timestamped packing photos before shipment.
- Seal proof files with SHA-256 hashes and an audit trail.
- Generate clean chargeback evidence PDFs from order, tracking, and proof data.
- Track dispute due dates and missing evidence.
- Keep control: review every response before using it.

## Demo Store Script

1. Install Backstop Proof on a development store.
2. Open Dashboard and point out proof captures, evidence packs, and dispute fallback.
3. Open Capture proof and select demo order `#1042`.
4. Upload three proof assets or use demo reset.
5. Seal the proof capture.
6. Generate an evidence pack and download the PDF.
7. Open Disputes and show demo dispute mode when Shopify Payments dispute access is unavailable.
8. Open Settings and show policy, retention, notification, and pricing placeholders.

## FAQ

### Does Backstop Proof guarantee chargeback wins?

No. Backstop Proof prepares merchant-reviewed evidence materials and does not guarantee dispute outcomes.

### Does the app change checkout or storefront themes?

No. The MVP is an embedded admin app and does not alter checkout or storefront themes.

### Can it submit Shopify Payments evidence automatically?

The MVP prepares a draft only after explicit merchant confirmation when Shopify permissions and feature flags allow it. Final submission remains merchant-controlled.

### What happens if dispute scopes are unavailable?

Order search, proof capture, manual evidence PDFs, and demo dispute mode still work.
